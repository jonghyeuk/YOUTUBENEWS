# EduNews

로컬에서 실행 가능한 React 애플리케이션입니다.

## 시작하기

### 의존성 설치

```bash
npm install
```

### 개발 서버 실행

```bash
npm run dev
```

애플리케이션이 [http://localhost:5173](http://localhost:5173)에서 실행됩니다.

### 프로덕션 빌드

```bash
npm run build
```

### 빌드 미리보기

```bash
npm run preview
```

## 기술 스택

- React 18
- Vite
- JavaScript/JSX
