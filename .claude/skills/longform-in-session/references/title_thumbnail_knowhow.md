# 제목·썸네일 문구 노하우 (2026-10 조사, 실제 유튜브 조회수 데이터 기반)

종혁님 평가: Claude가 처음 단 썸네일 문구·제목은 "맘에 안 든다". 아래는 실제 조회수 상위 영상을 보고 배운 것.
조사 방법: 유튜브 검색 결과를 조회수순으로 받아 제목·조회수·채널을 비교 (`yt_search` — SKILL.md 참고).

## 1. 이 장르(조선·실록·미스터리)에서 실제로 터진 제목 패턴
| 패턴 | 실제 예 (조회수) |
|---|---|
| **"지금도 설명되지 않는 / 현재까지 미스터리로 남은" + 조선시대 기록** | 현재까지도 미스터리로 남아있는 조선시대의 기이하고 소름끼치는 기록들 (285만) · 현재까지도 설명되지 않은 조선시대의 미스터리한 인물과 사건들 (222만) |
| **"실록에 기록된" + 구체적인 명사**(UFO·귀신·괴수·인어) | 조선왕조실록에 기록된 UFO 목격담 (38만) · 조선왕조실록에 기록된 정체불명의 괴수 (35만) · 실제 역사서에 남겨져 있는 조선시대 인어의 기록들 (24만) |
| **누구나 아는 비유로 인물 규정** | 시대가 버린 **조선의 노스트라다무스** 토정 이지함 (38만 — 이지함 영상 중 방송사 제외 1위) · 조선의 천재 아웃사이더들 (33만) |
| **진짜 기록 표시** | "실제 기록과 증언들", "실제 역사서에 남겨져 있는", "이게 실화였다고?!" |
| **구체적 상황 한 줄** | 말 한마디에 죽음을 피한 사내 (3.7만) · 아내를 위해 딱 한 번 보여준 묘기 (8.7만) |
| 끝에 장르 대괄호 | [미스터리] [괴담] [토정비결] |

반대로 약했던 것: 감탄사·추상어만 있는 제목("앞날을 훤히 내다보다~ 토정 이지함!!" 3.6만), 구체 명사 없는 "충격 실화".
몰아보기(40분~4시간) 영상이 조회수 최상위를 차지한다 → 편이 쌓이면 몰아보기 편집본도 만들 것.

## 2. 썸네일 문구 규칙
- 줄당 **8자 이내**, 전체 3~5단어. 모바일(시청의 약 70%)에서 읽혀야 한다.
- 제목을 **반복하지 말고 보완**: 썸네일 = 궁금증(질문을 던지고 답은 안 줌), 제목 = 검색 키워드 + 내용.
  썸네일 글자는 검색에 안 잡히니 키워드는 제목에.
- 궁금증 공백 예: "하루 먼저 / 알고 떠났다"(무엇을? 어떻게?) — 답은 영상에.
- 비유형: "조선의 / 노스트라다무스" — 이미 아는 이름에 기대면 한 번에 이해된다.
- 오른쪽 아래는 영상 길이 표시가 가리니 비운다. 대비 강하게(어두운 배경 + 금색·흰 글씨).
- 배경: 인물 정면 얼굴이 정중앙이면 가운데 글씨에 가린다 → 실루엣, 뒷모습, 인물이 한쪽에 있는 이야기 장면(예: 떠나는 사람 뒤로 그 집). 종혁님이 고른 B안 = 별밤 실루엣.

## 3. 제목 규칙 (종혁님 youtube_metadata_engine.py + 위 데이터)
- 50자 이내. 앞 20자 안에 가장 강한 말(모바일에서 잘림).
- 검색 키워드 필수: 인물 이름, 사건명, 조선왕조실록/실록, 토정비결처럼 사람들이 실제로 치는 말.
- 위 패턴 중 하나를 골라 구체적으로. 사실과 어긋나는 과장 금지(기록에 없는 "집이 무너졌다", 쓰지 않은 책의 "주인").
- 썸네일과 한 쌍으로 2~3세트를 내고 종혁님이 고르게 한다.
